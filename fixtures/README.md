# Fixtures

The P0 lot versions **no binary file**: the test scene is generated by `scene.build`
(two original stylised bipeds, a lantern, a floor, a camera) inside the temporary project of each test.
It is therefore reproducible, royalty-free and independent of any download.

The P1 `vitruvian/character.blend` fixture is present, with reproducible generation and CC0
provenance in [licenses/vitruvian.md](../licenses/vitruvian.md). It is stored through Git LFS.
Other fixtures below remain planned:

| Fixture | Source | License | Use |
| --- | --- | --- | --- |

| Humanoid animation library | Quaternius — Universal Animation Library | CC0 | `idle`, `walk`, `turn`… clips (FBX → GLB conversion through Blender) |
| Studio rig references | Blender Studio Snow / Rain (CloudRig) | CC-BY | referenced, never versioned (20–106 MB) |
